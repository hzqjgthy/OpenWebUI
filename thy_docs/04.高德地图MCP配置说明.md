# 高德地图 MCP 工具配置说明

## 一、快速开始

### 1. 已完成的配置

✅ 已安装：`amap-mcp-server`  
✅ 配置文件：`/root/miniconda3/envs/OpenWebUI/lib/python3.12/site-packages/open_webui/data/config.json`（方案 A - 默认位置）  
✅ 启动脚本：`/root/OpenWebUI_proj/start_openwebui_with_amap.sh`  
✅ API Key：已配置（your_api_key）

### 2. 一键启动（推荐）

```bash
/root/OpenWebUI_proj/start_openwebui_with_amap.sh
```

这个脚本会自动启动：
- Ollama 服务
- 高德地图 MCP 服务器（端口 8001）
- Open WebUI（端口 8080）

## 二、手动启动方式

### 方式 A：使用配置文件（自动管理）

```bash
# 1. 激活环境
conda activate OpenWebUI

# 2. 设置环境变量
export AMAP_MAPS_API_KEY="your_api_key"

# 3. 启动 Open WebUI（会自动启动 MCP 服务器）
open-webui serve
```

### 方式 B：手动启动 MCP 服务器

```bash
# 1. 激活环境
conda activate OpenWebUI

# 2. 启动 MCP 服务器（前台）
export AMAP_API_KEY="your_api_key"
amap-mcp-server --port 8001

# 3. 新开终端，启动 Open WebUI
conda activate OpenWebUI
open-webui serve
```

### 方式 C：后台运行

```bash
# 启动 MCP 服务器（后台）
export AMAP_API_KEY="your_api_key"
nohup amap-mcp-server --port 8001 > /tmp/amap_mcp.log 2>&1 &

# 启动 Open WebUI
open-webui serve
```

## 三、在 Open WebUI 中添加连接

### 方法 1：通过界面添加

1. 打开 Open WebUI：`http://localhost:8080`
2. 进入 **Settings（设置）** → **Admin Settings** → **Tools**
3. 点击 **添加连接** 或 **Add Connection**
4. 填写配置：
   - **URL**: `http://localhost:8001`
   - **OpenAPI 接口规范**: 选择 `URL`，输入 `openapi.json`
   - **认证方式**: 选择 `无` 或 `密钥 (Bearer)`
   - **API 密钥**: 留空
5. 点击 **保存**

### 方法 2：直接输入完整 URL

- **URL**: `http://localhost:8001/openapi.json`
- 关闭 "OpenAPI 接口规范" 开关
- 点击 **保存**

## 四、配置文件说明

### 配置文件位置
```
/root/miniconda3/envs/OpenWebUI/lib/python3.12/site-packages/open_webui/data/config.json
```

**说明**：配置文件应该放在 Open WebUI 的数据目录中，而不是 `~/.config`，这样 Open WebUI 才能正确读取。

### 配置文件内容
```json
{
  "mcpServers": {
    "amap-mcp-server": {
      "command": "python",
      "args": ["-m", "amap_mcp_server"],
      "env": {
        "AMAP_MAPS_API_KEY": "your_api_key"
      },
      "timeout": 30
    }
  }
}
```

### 配置说明
- `command`: 使用 `python` 命令
- `args`: 通过 `-m` 参数运行 `amap_mcp_server` 模块
- `env.AMAP_MAPS_API_KEY`: 你的高德地图 API Key（注意是 `AMAP_MAPS_API_KEY`）
- `timeout`: 超时时间（秒）

## 六、Autodl 端口映射配置

如果你在 Autodl 平台上运行，需要配置端口映射：

### 需要映射的端口
- **8080**: Open WebUI 界面
- **8001**: 高德地图 MCP 服务器
- **11434**: Ollama API（如果需要）

### 配置步骤
1. 打开 Autodl 控制台
2. 找到 "自定义服务" 或 "容器实例"
3. 添加端口映射：
   - 容器端口 `8080` → 映射到公网端口
   - 容器端口 `8001` → 映射到公网端口
4. 保存配置

## 七、故障排查

### 1. MCP 服务器无法启动

**检查端口占用：**
```bash
lsof -i :8001
netstat -tuln | grep 8001
```

**查看日志：**
```bash
tail -f /tmp/amap_mcp.log
```

**手动测试：**
```bash
export AMAP_API_KEY="your_api_key"
amap-mcp-server --port 8001
```

### 2. Open WebUI 无法连接 MCP 服务器

**测试 MCP 服务器是否运行：**
```bash
curl http://localhost:8001/health
curl http://localhost:8001/openapi.json
```

**测试 API 调用：**
```bash
curl "http://localhost:8001/api/geocode?address=北京市"
```

### 3. API 调用失败

**验证 API Key：**
```bash
curl "https://restapi.amap.com/v3/geocode/geo?key=your_api_key&address=北京市"
```

如果返回 `"status":"1"`，说明 API Key 有效。

**检查配额：**
- 登录高德开放平台：https://lbs.amap.com/
- 查看控制台 → 数据统计 → 调用量

### 4. 停止所有服务

```bash
# 停止 Open WebUI
pkill -f open-webui

# 停止 MCP 服务器
pkill -f amap-mcp-server

# 停止 Ollama
pkill -f ollama
```

## 八、高级配置

### 1. 修改 MCP 服务器端口

编辑配置文件 `~/.config/open-webui/config.json`：
```json
"args": ["--port", "8002"]
```

### 2. 添加更多 MCP 服务器

在配置文件中添加：
```json
{
  "mcpServers": {
    "amap": {
      // 高德地图配置
    },
    "other-service": {
      "name": "其他服务",
      "command": "other-mcp-server",
      "args": [],
      "enabled": true
    }
  }
}
```

### 3. 查看所有可用命令

```bash
amap-mcp-server --help
```
